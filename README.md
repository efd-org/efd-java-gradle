# efd-java-gradle

Simple Java Gradle hello-world starter project.

## Build
```bash
gradle build
```

This will compile the project and create the build artifacts in the `build/` directory, including:
- `build/libs/efd-hello-world-gradle-1.0.0.jar`

## Run
```bash
gradle run
```

Expected output:
```text
Hello, World!
```

## Test
```bash
gradle test
```
